# WattCycle on AWS

```
Viewer ──HTTPS──► CloudFront ──► Application Load Balancer
                                   ├─ /api/*, /ws, /health ─► ECS Fargate: api  (Node.js)  ─┐
                                   └─ everything else      ─► ECS Fargate: web  (Next.js)    │ Cloud Map: ai.wattcycle.local
                                                              ECS Fargate: ai   (FastAPI) ◄──┘
   api ──► RDS PostgreSQL        api ──► S3 (photos, presigned GET)     api ──► EventBridge bus (domain events, archived)
   ai  ──► S3 (model artifacts)  ai  ──► Bedrock (Claude assistant)      images built by CodeBuild → ECR
```

## What each AWS service does in WattCycle (implemented)

| Service | Used for | Code | Switch |
|---|---|---|---|
| **CloudFront** | HTTPS front door for the web app, API and WebSocket feed | `infra/terraform/compute.tf` | — |
| **ALB + ECS Fargate** | Runs web, api and ai containers; path routing for `/api`, `/ws` | `compute.tf` | — |
| **Cloud Map** | Private DNS between api ⇄ ai | `network.tf` | — |
| **RDS PostgreSQL 16** | Operational database, same schema as local | `server/src/database/db.ts` | `DATABASE_URL`, `DATABASE_SSL=true` |
| **S3** | Waste photos (put + 5-minute presigned GET) and trained model versions | `server/src/services/storage.ts`, `ai-service/ml/models/registry.py` | `S3_BUCKET` |
| **EventBridge** | Every domain event of the loop (pickup → … → AI training data), batched `PutEvents`; 30-day archive; feedback events routed to CloudWatch Logs | `server/src/services/eventbridge.ts`, `data.tf` | `EVENT_BUS_NAME` |
| **Amazon Bedrock** | WattCycle Intelligence assistant (Claude via `AnthropicBedrockMantle`, model `anthropic.claude-opus-5-5`) with tool calls into live data | `ai-service/app/assistant.py` | `ASSISTANT_PROVIDER=bedrock`, `AWS_REGION` |
| **Secrets Manager** | JWT secret, service key, database URL (generated by Terraform) | `data.tf` | — |
| **CodeBuild + ECR** | Builds the three images from GitHub, so no local Docker is needed | `build.tf` | — |
| **CloudWatch Logs** | Container logs, build logs, EventBridge feedback events | all | — |
| **IAM** | Task role limited to the bucket, the event bus and Bedrock invoke | `iam.tf` | — |

Credentials are never in code. Locally the SDKs read the AWS credential chain (`aws configure` / `aws sso login`); in ECS they use the task role.

## Not used (yet), and why
- **SageMaker:** training takes about 5 s per model on CPU, so the AI container trains in-process and mirrors versions to S3. SageMaker becomes worthwhile when training needs a GPU or real data at scale.
- **Amazon Location Service:** road distances come from OSRM on OpenStreetMap. Location Service needs a route-calculator resource; it would be a drop-in for `services/roads.ts`.
- **IoT Core:** there are no physical trucks or meters yet; positions come from the simulator.
- **ElastiCache / SQS:** a single API task with an in-process cache and event bus is enough at hackathon scale.

## Deploy

Install the [AWS CLI v2](https://aws.amazon.com/cli/) and [Terraform](https://developer.hashicorp.com/terraform/install). Sign in with `aws configure` or `aws sso login`. Push your branch to GitHub first: CodeBuild builds the branch you are on (or `DEPLOY_BRANCH=main`), and the script stops if your local commit differs from GitHub. Then run:

```bash
bash scripts/deploy-aws.sh
```

The script:
1. creates the ECR repos and the CodeBuild project;
2. builds and pushes the images in AWS;
3. applies the full stack;
4. prints the HTTPS URL.

On first start the API seeds the Delhi network into RDS and the AI service trains the models; allow about 3 minutes. Tear everything down with `bash scripts/deploy-aws.sh --destroy`.

**Bedrock:** model access to Claude must be enabled for the account and region in the Bedrock console. Otherwise set `assistant_provider = "offline"`.

**Approximate cost while running (ap-south-1):**

| Item | Approx. per month |
|---|---|
| NAT gateway | ~$35 |
| ALB | ~$20 |
| Fargate (api 0.5 vCPU, web 0.5 vCPU, ai 1 vCPU/4 GB) | ~$70 |
| RDS t4g.micro | ~$15 |

CloudFront, S3, EventBridge and Bedrock are pay-per-use. Destroy the stack when you're not demoing.
